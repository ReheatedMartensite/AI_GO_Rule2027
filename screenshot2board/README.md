# 截图摆棋（Screenshot2Board）

把一张围棋棋盘截图直接变成 Lizzieyzy 里摆好的局面：自动识别棋盘网格与黑白子，
生成 SGF 摆子棋谱，并可一键在 Lizzieyzy 中打开。

## 快速使用（推荐）

1. 双击仓库根目录的 **`截图摆棋.bat`**，打开图形界面。
2. 截一张棋盘图（`Win + Shift + S` 或截图工具均可），点 **「从剪贴板粘贴」**；
   也可以点 **「选择图片」** 打开本地文件（png / jpg / bmp 均可）。
3. 程序自动识别，预览区会画出识别结果（黑子 / 白子 / 空点）。
4. 点 **「在 Lizzieyzy 中打开」**——Lizzieyzy 会启动并直接摆出该局面，即可开始分析。

识别全过程本地完成，不需要网络。

## 识别错了怎么办

- **某个点识别错了**：直接在预览棋盘上点击那个交点，循环切换 空 → 黑 → 白 → 空。
- **整盘识别失败 / 位置偏移**：点 **「四角校准识别」**，然后按提示在原图上依次点击
  棋盘四个角部的星位交点（左上 → 右上 → 右下 → 左下），用四点透视重新识别。
  斜拍、有透视变形的照片请优先使用这种方式。
- **棋盘尺寸判断错**：右上角尺寸下拉框可以手动指定 19 / 13 / 9 路。
- 下方的贴目 / 下一手 / 规则按需修改（默认 7.5、黑先、Chinese）。

## 输出

- SGF 统一保存到 `screenshot2board/out/<图片名>_<时间戳>.sgf`（摆子 AB/AW 格式，
  Lizzieyzy、Sabaki 等所有主流软件均可打开）。
- 如果 Lizzieyzy 已经在运行，程序不会重复启动第二个实例（避免多开引擎占显存），
  而是自动打开输出目录，把 SGF 拖到 Lizzieyzy 窗口里即可。

## 命令行用法

```text
python screenshot2board\s2b.py <图片路径> [选项]

选项：
  -o, --output PATH   输出 SGF 路径（默认 out/ 目录）
  -n, --size          auto | 19 | 13 | 9（默认 auto）
  --komi 7.5          贴目
  --player B|W        下一手
  --rules Chinese     规则
  --open              保存后在 Lizzieyzy 中打开
  --debug DIR         输出叠加了检测网格与识别结果的调试图片
```

## 运行测试

```text
python screenshot2board\test_s2b.py
```

对内置测试语料（10 种主题 19 路、9/13 路、空盘、真实截图）做全量回归，
并验证 SGF 往返一致性。

## 技术说明

- 纯 OpenCV / numpy 实现，无深度学习依赖，秒级完成。
- 自动路径：优先用霍夫圆检测石子并拟合格点（密集局面稳健）；失败时回退到
  网格线投影拟合（空盘 / 稀疏局面）；两者都支持 19 / 13 / 9 路自动判断。
- 石子分类基于 LAB 色彩空间的中心 / 环带 / 背景对比特征，对常见主题
  （野狐、Lizzie、打印谱、实木棋盘照片等）测试准确率 100%。
- 识别核心在 `recognizer.py`；入口与集成逻辑在 `s2b_core.py`；
  GUI 在 `s2b_gui.py`；命令行在 `s2b.py`。

## 已知局限

- 棋盘以外的界面元素（头像、按钮里的圆点）理论上可能被误认成石子，格点拟合
  已尽量排除；如遇个别误判，点击交点手动纠正即可。
- 严重透视变形 / 倾斜超过一定角度的照片需要「四角校准识别」。
- 需要本机装有 Python 3 与 opencv-python、numpy（Pillow 可选，用于剪贴板）。
