압축만 풀면 바로 쓰는 바둑 AI 패키지예요. **Lizzieyzy** 그래픽 인터페이스가 대국·분석 핵심 기능을 제공하고
(소스 미변경) **KataGo** 엔진이 두뇌를 담당하며 Java 실행 환경도 내장되어 있어요.
이 저장소의 기여 = **수정**(형세판단 엔진 설정) + **확장**(스크린샷 배치 / 온라인 대국 /
실시간 관전 동기화 자체 도구 3종) + **통합**(transformer 엔진 T18/T28 옵션).

---

## ✨ 핵심 기능

- **4 엔진 구성**: KataGo **18b / 28b** 정통 가중치에 더해 신세대 transformer 계열
  **T18 (tf2-b10c384)**, **T28 (tf3-b10c512)**(KataGo 1.18.1 내장)까지 내장, 프로그램 안에서 한 번에 전환
- **원클릭 성능 튜닝**: `点我首次运行调优.bat`(첫 실행 튜닝)을 더블클릭하면 자동으로 완료돼요 (v1.1)
- **진짜 휴대용**: OpenJDK 17을 내장해 압축만 풀면 바로 쓰고, USB에 담아 다닐 수도 있어요
- **다양한 그래픽카드 호환**: OpenCL 범용 빌드로 NVIDIA / AMD / Intel 주류 GPU를 지원해요
- 🆕 **스크린샷 배치** (v1.2): 스크린샷 → 바둑판 자동 인식 → Lizzieyzy에서 한 번에 국면 배치
- 🆕 **온라인 대국** (v1.2): 친구와 LAN/인터넷으로 대국, AI 실시간 승률 패널도 선택 가능.
   2027 중국 규칙 판정(무승부/먼저 손 뗀 쪽 승 규정)도 지원해요
- 🆕 **실시간 창 관전** (v1.2): 아무 창이나 고르면 몇 초마다 그 안의 바둑판을 자동 인식해 실시간으로 국면을 재현하고, KataGo 승률·형세 분석이 진행에 맞춰 갱신돼요
- 🆕 **형세판단 수정** (v1.2): v1.1에서 형세판단 엔진을 불러오지 못하던 문제를 수정했어요

## 🚀 빠른 시작

1. 아무 위치에 압축을 풀어 주세요 (**중국어(전자 문자)와 공백이 없는 경로를 권장해요**)
2. `Lizzieyzy-2.5.3-win64.exe`를 더블클릭해 실행하세요
3. 엔진 전환으로 **18b / 28b / T18 / T28** 4개 엔진을 고르고, 대국을 시작하거나 SGF를 불러와 분석하세요
   (T18/T28은 신세대 transformer 엔진: 같은 등급의 수당 기력이 더 높고 T18은 메모리도 적게 써요.
   Intel iGPU에서는 OpenCL transformer 커널이 아직 미성숙해 원래 속도가 약간 느리고, NVIDIA 카드에서는 더 빨라요)
4. ⭐ 강력 권장: `点我首次运行调优.bat`(첫 실행 튜닝)을 더블클릭해 성능 튜닝을 완료하세요 (약 2~6분)

> 처음 실행하면 OpenCL 자동 튜닝이 진행돼요(3~5분). 정상적인 현상이니 조금만 기다려 주세요.

## 🆕 v1.2 새 기능

### 1️⃣ 형세판단 (수정 완료)

v1.1에서는 전용 추정 엔진 설정이 없어서 이 기능을 쓸 수 없었는데, v1.2에서 수정했고
실제 환경에서 종단 간 검증을 마쳤어요.

- Lizzieyzy에서 **`/` 키**를 누르면 형세판단이 실행되고, 한 번 더 누르면 해제돼요
- 엔진이 백그라운드에 상주해서 처음엔 약 3초, 이후에는 즉시 갱신돼요
- 자세한 사용법은 Lizzieyzy에 포함된 설명 문서를 참고하세요

### 2️⃣ 스크린샷 배치 (Screenshot2Board)

대국 스크린샷이나 중계 화면을 보고 KataGo가 바로 분석하게 하고 싶다면, 루트 폴더의
**`截图摆棋.bat`**(스크린샷 배치)를 더블클릭하세요:

1. `Win + Shift + S`로 스크린샷 → 「**클립보드에서 붙여넣기**」 클릭 (또는 「이미지 선택」)
2. 바둑판과 흑백 돌을 자동으로 인식해요 (19/13/9로 판 자동 판별)
3. 「**Lizzieyzy에서 열기**」 클릭 — 국면이 즉시 배치되고 바로 분석을 시작할 수 있어요

인식이 틀렸을 때는: 미리보기 바둑판의 교차점을 클릭해 직접 고칠 수 있어요 (빈점→흑→백 순환).
비스듬히 찍은 사진이나 복잡한 이미지는 「네 모서리 보정」 모드를 쓰세요. 인식은 로컬 OpenCV로 처리되고 테스트 말뭉치 정확도는 **100%**예요. 자세한 내용은 [`screenshot2board/README.md`](./screenshot2board/README.md)를 참고하세요.

### 3️⃣ 온라인 대국 (Netplay)

친구와 온라인으로 바둑을 둬요. 양쪽 모두 이 툴킷만 쓰면 서버가 전혀 필요 없어요:

1. **`联机对弈.bat`**(온라인 대국)을 더블클릭하고, 방장은 「대국 만들기」를 선택해요 (화면에 IP와 포트가 표시돼요)
2. 상대는 「대국 참여」를 선택하고 방장의 IP를 입력하면 연결돼요
3. 완전한 규칙 엔진 내장 (돌 잡기/자살 수 금지/패(劫)), 무르기 요청·기권·채팅도 지원해요.
   **2027 중국 규칙 판정**(흑 3.5자=7점 공제, 흑 184자 무승부, 승자 필요 시 백 승/먼저 손 뗀 쪽 승 규정 선택,
   죽은 돌 클릭 후 재판정)도 지원해요
4. 선택해서 **AI 패널**을 켤 수 있어요: 매 수 뒤에 승률과 세력 귀속 히트맵을 표시해요
5. 대국이 끝나면 SGF로 저장되고, 한 번에 Lizzieyzy에서 복기할 수 있어요

> 같은 LAN이면 직접 연결돼요 (처음 뜨는 방화벽 알림에서 「허용」을 클릭하세요); 공용 인터넷을 넘으려면
> 방장 쪽에서 포트 포워딩(기본 포트 19864)이나 내부망 통과 도구가 필요해요. 자세한 내용은
> [`netplay/README.md`](./netplay/README.md)를 참고하세요.

### 4️⃣ 실시간 창 관전 (BoardWatch)

아무 창에서 진행 중인 대국을 KataGo가 실시간으로 분석하게 하고 싶다면, 루트 폴더의
**`实时盯盘.bat`**(실시간 창 관전)를 더블클릭하세요:

1. 드롭다운에서 감시할 창을 고르세요(대국 프로그램·웹 중계·복기 화면 모두 가능. 목록에 프로세스명도 표시되고, 열거되지 않는 창——WeChat 미니프로그램 등——는 「**창 클릭 선택**」 버튼 누르고 5초 안에 대상을 클릭하면 돼요). 간격(기본 5초)을 정한 뒤 「**감시 시작**」 클릭
2. 몇 초마다 그 창을 자동 캡처해 안의 바둑판을 인식하고(스크린샷 배치와 같은 인식 코어, 19/13/9로 자동 판별), 수를 증분적으로 추정해 자체 화면에 실시간 재현해요. **다른 창에 완전히 가려진 백그라운드 창도 그대로 캡처돼요**(ok-ww/ok-nte와 같은 PrintWindow 경로). 「최소화 창 자동 복원」에 체크하면 최소화된 창도 자동으로 복원해 감시를 계속해요
3. 「**AI 패널**」을 체크하면 바둑판이 바뀔 때마다 KataGo가 실행: 흑 승률·목수 차·세력 귀속 히트맵이 진행에 따라 갱신돼요
4. 오른쪽 썸네일에는 인식된 바둑판 네 모서리가 초록 박스로 표시돼 정렬을 확인할 수 있어요. 언제든 SGF를 저장하거나 한 번에 Lizzieyzy 심층 복기로 넘어갈 수 있어요

추적은 영상을 유일한 참값으로 다뤄요: 정상 착수·돌 잡기는 수로 추정하고, 화면이 크게 바뀌면 자동 재동기화해서
재현 바둑판이 항상 창과 일치해요. 인식·추적·분석은 독립 레이어라 인식 실패 프레임은 건너뛸 뿐 감시는 계속돼요.
자동 테스트 65개를 모두 통과했어요(실제 창 캡처+인식, 실제 엔진 분석 포함).

**Lizzieyzy 동기화**: 「Lizzieyzy에 동기화」에 체크하면 인식한 국면이 Lizzieyzy 복기 화면에
실시간 반영돼요——승률 그래프·후보 수·형세판단이 그대로 작동하고 수동 가져오기가 필요 없어요.
Lizzieyzy에서 **Alt+O**를 한 번 누르면 증분 프로토콜 채널이 켜지고(한 수씩 배치, 포커스 뺏기 없음),
끄면 자동으로 클립보드 채널이 쓰여요(갱신 때마다 Lizzieyzy가 잠깐 앞으로 나와요). **차례는 자동
정렬**돼요(교대 착수로 추정하고 어긋나면 pass로 보정——형세판단이 차례 미스로 무너지지 않아요).
**샘플링 간격은 감시 중에도 실시간 조정 가능**(빠른 대국/느린 대국 대응). 자세한 내용은
[`boardwatch/README.md`](./boardwatch/README.md)를 참고하세요.

## ⚠️ 온라인 관전 기능 안내

Lizzieyzy에 내장된 「이커(弈客) 라이브/로비」, 「예후(野狐) 링크 따라가기」 같은 **온라인 관전** 기능은
이커(rtgame.yikeweiqi.com)와 예후(hlws.huanle.qq.com)의 실시간 푸시
서비스에 의존해요. 테스트(2026-10) 결과, **이 두 제3자 서버는 모두 서비스를 중단했어요**. 상위
서비스 종료라서 클라이언트에서는 고칠 수 없어요. 게다가 두 플랫폼의 현재 대국 데이터 API는 모두
비공개예요(이커는 로그인 토큰 필요, 예후 라이브는 로그인 상태의 푸시 연결 필요)라서 서드파티 도구가
의존하기엔 부적합해요. 일반 SGF 링크를 온라인으로 여는 기능은 여전히 쓸 수 있어요.
온라인으로 바둑을 두려면 이 패키지에 새로 추가된 온라인 대국 기능을 사용하세요.

## 📖 2027 중국 규칙 지원

중국기기협회의 『바둑 경기 규칙(2027 시행판)』이 2027-01-01부터 시행돼요. 핵심 변화:
**흑이 3.5자(=7점) 공제**(기존 3.75자/7.5점), 흑 총 **184자면 무승부**——공식전 최초의
무승부 도입이에요. 승자가 필요하면 규정은 2택: **① 백 승, ② 먼저 손을 뗀 쪽 승**.

이 패키지의 도구는 이미 지원해요:

| 도구 | 지원 내용 |
| :--- | :--- |
| **온라인 대국** | 두 번의 패스로 끝나면 신규칙 집계 판정(흑 3.5자 공제, 흑 184자 무승부). 무승부 시 규정 2택 대화상자(백 승 / 먼저 손 뗀 쪽 승 / 무승부 유지). **판 위의 돌을 클릭해 죽은 돌을 표시하면 즉시 재판정**. 먼저 손 뗀 쪽을 기록·표시. 결과는 SGF RE에 기록(무승부=RE[0]) |
| **실시간 창 관전** | 감시한 대국이 끝나면 2027 룰 근사 집계와 먼저 손 뗀 쪽 표시(모든 돌을 살아있는 것으로 가정) |
| **KataGo 엔진** | 7점 컴/임의 컴은 엔진 고유 기능이고, 무승부 국면도 정확히 분석(50%) |

**한계**: 집계 판정에는 죽은 돌 정보가 필요——온라인 대국에서는 클릭으로 표시하고,
실시간 창 관전은 "모든 돌을 살아있는 것으로 가정"하는 근사예요(화면에서 죽은 돌을
판단할 수 없음). "먼저 손 뗀 쪽 승"은 대국 종료 판정이라 KataGo 엔진은 관여하지 않아요.

## 💻 하드웨어 호환성과 성능

이 통합 패키지는 다음 플랫폼에서 호환성 테스트를 마쳤어요:

| 브랜드 | 테스트한 모델 |
| :--- | :--- |
| **NVIDIA** | RTX 50 시리즈, GTX 10 시리즈, GTX1660Super (튜링 아키텍처) |
| **AMD** | RX 6000 시리즈 |
| **Intel** | Xe 내장 그래픽 (Tiger Lake / Alder Lake / UHD 770 등) |

2012년 이후 OpenCL 1.2+를 지원하는 주류 그래픽카드는 대부분 실행할 수 있어요. 원클릭 튜닝을 실행하면
최적 설정이 자동으로 잡혀요. 자세한 성능 데이터는 [PERFORMANCE.md](./PERFORMANCE.md)를 참고하세요.

## ❓ 자주 묻는 질문

- **bat 파일을 더블클릭해도 반응이 없거나 오류가 나요**: 마우스 오른쪽 클릭으로 「관리자 권한으로 실행」; 경로에 중국어와 공백이 없는지 확인하세요
- **`CL_PLATFORM_NOT_FOUND_KHR`**: 그래픽 드라이버를 업데이트하세요 (OpenCL 1.2+ 지원 필요)
- **AMD 그래픽카드에서 `Got nonfinite for policy sum` 오류가 나요**: 두 엔진의
  `default_gtp.cfg` 끝에 `openclUseFP16 = false` 한 줄을 추가하세요
- **형세판단이 반응하지 않아요**: 기본 키보드의 `/` 키를 눌렀는지, Lizzieyzy 메인 창에 포커스가 있는지 확인하세요
- **온라인 대국이 연결되지 않아요**: 방화벽에서 허용됐는지 확인하세요 (처음 실행할 때 「허용」 클릭); 공용 인터넷에서는
  포트 포워딩이나 내부망 통과가 필요해요
- **스크린샷 인식이 실패해요**: 「네 모서리 보정 인식」으로 네 모서리를 직접 클릭하거나, 스크린샷에
  바둑판 전체가 들어 있는지 확인하세요
- **T18 / T28은 뭐고 무엇을 골라야 하나요?**: KataGo 신세대 transformer 네트워크예요
  (T18=tf2-b10c384, T28=tf3-b10c512. 내장된 KataGo 1.18.1 필요). 수당 기력은 같은 등급의
  18b/28b보다 높아요. Intel iGPU에서는 OpenCL transformer 커널이 아직 미성숙해 원래 속도는
  같은 등급 CNN보다 약간 느려요(PERFORMANCE.md 참고). NVIDIA 카드에서는 더 빨라요. T18 메모리는
  18b의 40% 수준예요. 직접 전환해 비교해 보세요——18b/28b는 기본값 그대로예요

## 🧪 테스트와 품질

v1.2의 새 기능에는 모두 자동 회귀 테스트가 따라와서 내 컴퓨터에서 다시 확인할 수 있어요:

```text
python screenshot2board\test_s2b.py      # 스크린샷 인식: 10개 테마 말뭉치 + SGF 왕복
python netplay\test_netplay.py           # 온라인 대국: 규칙 + 프로토콜 루프백 + UI 통합
python boardwatch\test_boardwatch.py     # 실시간 관전: 추적 + 창 캡처 + 실엔진 분석
python boardwatch\e2e_lizzie_sync.py     # 감시→Lizzieyzy 동기화 E2E (데스크톱 한가할 때)
```

(로컬에 Python 3와 opencv-python이 설치되어 있어야 해요. 테스트는 일반 사용에 영향을 주지 않아요.)
