解凍するだけで使える囲碁 AI パッケージです。**Lizzieyzy** グラフィックインターフェースが対局・解析のコア機能を提供し
（ソースは未改変）、**KataGo** エンジンが思考を担い、Java 実行環境も同梱しています。
このリポジトリの貢献 = **修正**（形勢判断エンジン設定）+ **拡張**（スクリーンショット配置 / ネット対局 /
リアルタイム監視同期の自作ツール 3 種）+ **統合**（transformer エンジン T18/T28 対応）。

## ✨ 主な特徴

- **4 エンジン構成**：KataGo **18b / 28b** の定番重みに加え、新世代 transformer 系
  **T18 (tf2-b10c384)** と **T28 (tf3-b10c512)**（KataGo 1.18.1 同梱）を同梱、ソフト内でワンクリック切替
- **ワンクリック性能チューニング**：`点我首次运行调优.bat`（初回起動チューニング）をダブルクリックするだけで自動で完了 (v1.1)
- **真のポータブル**：OpenJDK 17 を同梱、解凍すればすぐ使え、USB メモリでの持ち運びも可能
- **幅広い GPU 対応**：OpenCL 汎用ビルドで、NVIDIA / AMD / Intel の主流 GPU をサポート
- 🆕 **スクリーンショット配置** (v1.2)：スクリーンショット → 碁盤を自動認識 → Lizzieyzy でワンクリック配置
- 🆕 **ネット対局** (v1.2)：友人と LAN／インターネットで対局、AI リアルタイム勝率パネルも選択可能。
   2027 中国ルール判定（引き分け／先手停止者勝規程）に対応
- 🆕 **ネット観戦ウォッチャー** (v1.2)：任意のウィンドウを選ぶと、数秒ごとにその中の碁盤を自動認識し、リアルタイムで盤面を再現しながら KataGo の勝率・形势解析を進行に合わせて更新
- 🆕 **形勢判断の修正** (v1.2)：v1.1 で形勢判断エンジンが読み込めない問題を修正

## 🚀 はじめかた

1. 任意の場所に解凍してください（**中国語（全角文字）やスペースを含まないパスを推奨**）
2. `Lizzieyzy-2.5.3-win64.exe` をダブルクリックして起動
3. エンジン切替で **18b / 28b / T18 / T28** の 4 エンジンを切り替え、対局を始めるか SGF を読み込んで解析
   （T18/T28 は新世代 transformer エンジン：同クラスの 1 手あたり棋力が高く、T18 はメモリ消費も小さい。
   Intel iGPU では OpenCL の transformer カーネルが未成熟なため生速度はやや劣り、NVIDIA 卡ではより速い）
4. ⭐ 強くおすすめ：`点我首次运行调优.bat`（初回起動チューニング）をダブルクリックして性能チューニングを完了してください（約 2～6 分）

> 初回起動時は OpenCL の自動チューニングが行われます（3～5 分）。正常な動作ですので、しばらくお待ちください。

## 🆕 v1.2 の新機能

### 1️⃣ 形勢判断（修正済み）

v1.1 では専用の推定エンジン設定が不足していたためこの機能は使えませんでしたが、v1.2 で修正し、
実環境でエンドツーエンドの検証を行いました。

- Lizzieyzy で **`/` キー**を押すと形勢判断が実行され、もう一度押すと解除されます
- エンジンはバックグラウンドで常駐し、初回は約 3 秒、以降は瞬時に更新されます
- 詳しい使い方は Lizzieyzy 同梱の説明書をご覧ください

### 2️⃣ スクリーンショット配置（Screenshot2Board）

対局のスクリーンショットや中継画面を見かけて、KataGo にすぐ解析させたい場合は、ルートフォルダの
**`截图摆棋.bat`**（スクリーンショット配置）をダブルクリックしてください：

1. `Win + Shift + S` でスクリーンショット →「**クリップボードから貼り付け**」をクリック（または「画像を選択」）
2. 碁盤と黒白の石を自動認識（19/13/9 路盤を自動判定）
3. 「**Lizzieyzy で開く**」をクリック —— 局面が即座に配置され、すぐに解析を始められます

認識を誤った場合：プレビューの碁盤の交点をクリックして手動で修正できます（空→黒→白の順で切り替わります）。
斜めからの撮影や複雑な画像には「四隅キャリブレーション」モードが使えます。認識はローカルの OpenCV で行われ、テストコーパスでの正解率は **100%** です。詳しくは [`screenshot2board/README.md`](./screenshot2board/README.md) をご覧ください。

### 3️⃣ ネット対局（Netplay）

友人とオンラインで対局できます。両者がこのツールキットを使えば、サーバーは一切不要です：

1. **`联机对弈.bat`**（ネット対局）をダブルクリックし、ホスト側は「対局を作成」を選択（画面に IP とポートが表示されます）
2. 相手は「対局に参加」を選び、ホストの IP を入力すれば接続できます
3. 完全なルールエンジン内蔵（石を取る／自殺手の禁止／劫）で、待った要求・投了・チャットにも対応。
   **2027 中国ルール判定**（黒 3.5 子コミ＝7 点、黒 184 子で引き分け、勝敗必須時は白勝／先手停止者勝の規程選択、   死子クリック判定し直し）に対応
4. オプションで **AI パネル**を有効化：各手の後に勝率と勢力帰属ヒートマップを表示
5. 対局終了時に SGF を保存し、ワンクリックで Lizzieyzy で検討できます

> 同じ LAN 内なら直接接続できます（初回に表示されるファイアウォールの通知では「許可」をクリックしてください）；インターネット越しの場合は
> ホスト側でのポート転送（デフォルトポート 19864）または NAT 越えツールが必要です。詳しくは
> [`netplay/README.md`](./netplay/README.md) をご覧ください。

### 4️⃣ リアルタイム監視（BoardWatch）

任意のウィンドウ内で進行する対局を KataGo にリアルタイム解析させたい場合は、ルートフォルダの
**`实时盯盘.bat`**（リアルタイム監視）をダブルクリック：

1. ドロップダウンから監視したいウィンドウを選び（対局ソフト・配信・検討画面など。一覧にはプロセス名も表示され、列挙できないウィンドウ——WeChat ミニプログラムなど——は「**ウィンドウをクリック選択**」ボタンで 5 秒以内に対象をクリックすれば選べます）、間隔（デフォルト 5 秒）を設定して「**監視開始**」
2. 数秒ごとにウィンドウを自動キャプチャし、中の碁盤を認識（スクリーンショット配置と同じ認識コア、19/13/9 路自動判定）、着法を増分的に推定して自画面にリアルタイム再現。**他のウィンドウに完全に隠されたバックグラウンドのウィンドウもそのままキャプチャできます**（ok-ww/ok-nte と同じ PrintWindow 経路）。「最小化ウィンドウを自動で元に戻す」にチェックすると、最小化されたウィンドウも自動復元して監視を続けます
3. 「**AI パネル**」をチェックすると、盤面が変わるたびに KataGo が起動：黒の勝率・目数差・勢力帰属ヒートマップが進行に合わせて更新
4. 右側サムネイルには認識した碁盤の四隅が緑枠で表示され、位置合わせを確認できます。いつでも SGF を保存、ワンクリックで Lizzieyzy の詳細検討へ

追跡は映像を唯一の真値として扱います：通常の着手・石取りは着法として推定し、画面が大きく変われば自動で再同期するため、
再現盤面は常にウィンドウと一致します。認識・追跡・解析は独立したレイヤーで、認識に失敗したフレームはスキップされるだけで監視は続行します。
自動テスト 65 項目すべて合格（実ウィンドウのキャプチャ＋認識、実エンジン解析を含む）。

**Lizzieyzy への同期**：「Lizzieyzy に同期」にチェックを入れると、認識した局面が Lizzieyzy の
検討画面にリアルタイムで反映され——勝率グラフ・候補手・形勢判断はそのまま動き続け、手動インポートは不要です。
Lizzieyzy 内で一度 **Alt+O** を押すと増分プロトコル通道が有効になり（一手ずつ配置、フォーカスを奪いません）、
未押下時は自動でクリップボード通道が使われます（更新のたびに Lizzieyzy が一瞬前面に来ます）。**手番は自動で
整合**されます（交互着手から推定し、ずれれば pass で補正——形勢判断が手番ミスで崩れません）。**サンプリング
間隔は監視中もリアルタイムに変更可能**（速碁／ゆっくりした対局に対応）。詳しくは
[`boardwatch/README.md`](./boardwatch/README.md) をご覧ください。

## ⚠️ オンライン観戦機能について

Lizzieyzy 同梱の「弈客ライブ／ロビー」「野狐リンク観戦」といった**オンライン観戦**機能は、
弈客（rtgame.yikeweiqi.com）と野狐（hlws.huanle.qq.com）のリアルタイム配信
サービスに依存しています。テスト（2026-10）では、**この 2 つのサードパーティサーバーはいずれもサービスを終了しており**、
上流サービスの終了であるためクライアント側では修復できません。さらに、両プラットフォームの現行の対局データ API は
いずれも非公開です（弈客はログイントークンが必要、野狐のライブ配信はログイン状態のプッシュ接続が必要）ため、
サードパーティツールが依存するのは適切ではありません。通常の SGF リンクをオンラインで開く機能は引き続き利用できます。
オンラインで対局したい場合は、本パッケージで追加されたネット対局機能をご利用ください。

## 📖 2027 中国ルール対応

中国囲碁協会の『囲碁競賽規則（2027 試行版）』は 2027-01-01 から試行開始。主な変更点：
**黒が 3.5 子（=7 点）コミ**（従来は 3.75 子／7.5 点）、黒の総得点 **184 子で引き分け**
——公式戦初の引き分け導入です。勝敗必須の場合、規程は 2 択：**① 白の勝ち、② 先に手を
抜いた（パスした）側の勝ち**。

本パッケージのツールはすでに対応済み：

| ツール | 対応内容 |
| :--- | :--- |
| **ネット対局** | 双パス終局後、新ルールで自動数子判定（黒 3.5 子コミ、黒 184 子引き分け）。引き分け時は規程 2 択のダイアログ（白勝／先手停止者勝／引き分け維持）。**盤上の石をクリックして死石をマークすると即再判定**。先手停止者を記録・表示。結果は SGF RE に書き込み（引き分け=RE[0]） |
| **リアルタイム監視** | 監視対象の対局終了時、2027 ルールの近似数子判定と先手停止者を表示（全石を活石とみなす近似） |
| **KataGo エンジン** | 7 点コミ／任意コミはエンジン本来の機能で、引き分け局面も正しく解析（50%） |

**制限事項**：数子判定には死石情報が必要——ネット対局ではクリックでマーク、
リアルタイム監視は「全石を活石とみなす」近似です（画面からは死石を判定できない）。
「先手停止者勝」は対局終了時の裁定であり、KataGo エンジン自体は関与しません。

## ❓ よくある質問

- **bat をダブルクリックしても反応しない／エラーが出る**：右クリックして「管理者として実行」；パスに中国語やスペースが含まれていないか確認してください
- **`CL_PLATFORM_NOT_FOUND_KHR`**：グラフィックスドライバーを更新してください（OpenCL 1.2+ 対応が必要）
- **AMD GPU で `Got nonfinite for policy sum` と表示される**：両エンジンの
  `default_gtp.cfg` の末尾に `openclUseFP16 = false` の 1 行を追加してください
- **形勢判断が反応しない**：メインキーボードの `/` キーを押しているか、Lizzieyzy のメインウィンドウにフォーカスがあるか確認してください
- **ネット対局で接続できない**：ファイアウォールの許可を確認してください（初回実行時に「許可」をクリック）；インターネット越しの場合は
  ポート転送または NAT 越えが必要です
- **スクリーンショットの認識に失敗する**：「四隅キャリブレーション認識」で 4 つの隅を手動でクリック；またはスクリーンショットに
  碁盤全体が含まれているか確認してください
- **T18 / T28 とは？どちらを選ぶ？**：KataGo の新世代 transformer ネットワークです
  （T18=tf2-b10c384、T28=tf3-b10c512。同梱の KataGo 1.18.1 が必要）。1 手あたりの棋力は
  同クラスの 18b/28b より高いです。Intel iGPU では OpenCL の transformer カーネルが未成熟なため
  生速度は同クラスの CNN よりやや劣ります（PERFORMANCE.md 参照）。NVIDIA GPU ではより速くなります。
  T18 のメモリ消費は 18b の 40% 程度。自分で切り替えて比較してください——18b/28b は既定のままです
