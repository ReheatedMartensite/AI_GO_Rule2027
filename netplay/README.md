# 联机对弈（Netplay）

两位玩家通过**局域网或互联网**用本整合包对弈围棋，并可选开启 KataGo 实时
胜率 / 归属热图面板。对局结束后一键保存 SGF，或在 Lizzieyzy 中打开复盘。

## 快速开始

1. 双击仓库根目录的 **`联机对弈.bat`**。
2. **主机方**：输入昵称 → 选「创建对局」→ 点「开始」→ 界面会显示
   `本机 IP` 和端口（默认 19864），把这两个数字告诉对方，然后等待。
3. **加入方**：输入昵称 → 选「加入对局」→ 填入主机的 IP 和端口 → 点「开始」。
4. 连接成功后自动进入棋盘界面，主机执黑先行；轮到自己时点击交点落子。

## 界面功能

- **虚着（Pass）**：连续两次虚着即结束对局。
- **悔棋请求**：向对方发送悔棋请求，对方同意后回退最后一手。
- **认输**：确认后对局结束。
- **聊天**：左下角输入框 + 回车发送，双方可见。
- **AI 面板**（默认关闭）：勾选后启动 18b 引擎，每次落子后显示
  黑方胜率、目数差估算，并在棋盘上以半透明色块标出双方势力
  （红 = 黑方地盘，蓝 = 白方地盘）。引擎启动失败会自动降级，不影响对弈。
- **保存 SGF / 在 Lizzieyzy 打开复盘**：棋谱保存在 `netplay/games/`，
  可直接在 Lizzieyzy 中打开做深度分析。

## 网络说明（重要）

- **同一局域网**（家里/办公室/手机热点）：直接用界面显示的 IP 连接即可。
- 首次启动时 Windows 会弹出**防火墙提示**，务必勾选「允许访问」，
  否则对方连不进来。
- **跨公网**（两地远程）：需要主机方在路由器上做**端口映射**（默认端口 19864），
  或双方使用内网穿透工具（如 frp、Tailscale、ZeroTier 等）组网后按局域网方式连接。
- 可选 4 位数字口令：设置后，对方必须输入相同口令才能连入。

## 规则引擎

- 纯 Python 实现完整行棋规则：**提子、禁自杀、禁全局同形（劫）**。
- 支持自定义贴目（默认 7.5）与棋盘尺寸（9 / 13 / 19 路）。
- 悔棋需要对方同意；双方棋盘由协议自动同步，手数不一致会立即报告。

## 2027 中国规则判定（新增）

对局以双虚着收束后，工具自动按 **《围棋竞赛规则（2027 试行版）》** 数子判定：

- 黑贴 3.5 子（=贴 7 点），黑总得 **184 子即为平局**（9/13 路按比例类推）
- 判定结果显示黑/白子数与胜负；平局且需分胜负时，按规程二选一：
  **方案一判白方胜** / **方案二判先停手一方胜**（也可保持平局）
- 终局后**点击棋盘上的棋子可标注死子**（红叉标记），判定实时重算
- 结果写入 SGF 的 RE 属性（平局为 RE[0]，规程判定为 B+/W+）

KataGo 引擎本身原生支持任意贴目（含贴 7 点的和棋局面）；先停手判胜属
赛事判定规则，由本工具在终局时执行。棋谱联动 Lizzieyzy 复盘时同样携带
正确轮次。

## 运行测试

```text
python netplay\test_netplay.py
```

覆盖规则引擎（提子/自杀/劫/悔棋）、网络协议回环（真实套接字）、
界面集成（真实事件驱动对局）以及 KataGo 面板（需引擎存在，可自动跳过）。

## 技术说明

- 仅使用 Python 标准库（socket / threading / tkinter），无第三方依赖。
- 协议为换行分隔的 JSON 文本，主机为权威端，所有着法带序号校验。
- AI 面板复用 `engine_18b` 的估计引擎配置（单线程、低占用），
  通过 `kata-raw-nn 0` 读取胜率与归属，与 Lizzieyzy 形势判断同一套流程。

## 已知限制

- 不做自动数子终局：双虚着后由双方自行确认结果（可参考 AI 面板的目数估算）。
- 断线后不重连（棋盘保留，可保存棋谱）；一局仅支持两名玩家。
- AI 面板显示的是单次前向传播的快速估计（非搜索），仅供对局参考，
  精确分析请在对局后用 Lizzieyzy 复盘。
